# job-application-tailor

## User inputs
If the job description or resume is missing, ask for the missing document before continuing.

## Procedure
1. Read the supplied job description and the user’s resume or application materials.
2. Apply the job requirements and keywords to tailor the user’s materials, emphasizing the most relevant skills and experiences.
3. Check that the tailored content matches the job description, is clear and concise, and does not invent any skills, experiences, or qualifications.
4. Produce the final tailored resume, cover letter, or application response in a polished format ready for the user to review.

## Output
Return a tailored resume, cover letter, or application response with these sections: final tailored content, key changes made, and relevant job requirements addressed.
The result should make the strongest matches between the user’s experience and the job requirements visible.

## Boundaries
Do not invent, exaggerate, or add skills, experiences, qualifications, or accomplishments that the user did not provide.
Ask me before making major changes that alter the meaning of my original experience or qualifications.
When the application cannot be fully tailored because information is missing, report what information is missing and what is needed to complete it.
